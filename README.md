# Student Grade Analysis

> Reads student scores from a text file, calculates averages, and ranks students by average grade.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)

## Skills demonstrated

File I/O, data parsing, list processing, aggregation, and sorting.

## Project files

[Python script](Assignment2.py)

**Input:** `Assignment2input.txt` must be supplied separately; it is not currently included. Each line contains a student name followed by numeric scores.

## How to run

From the repository directory, use Python 3:

```sh
python Assignment2.py
```
